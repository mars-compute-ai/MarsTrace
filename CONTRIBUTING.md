# Contributing

Issues are welcome: report a bug, a confusing message or a missing feature at
https://github.com/mars-compute-ai/MarsTrace/issues. Include the client version
(`pip show mars-trace`), the command you ran and, for a job, its job id.

Pull requests are not accepted for now. The client is source-available under the
PolyForm Noncommercial License 1.0.0, and we have no contributor agreement yet that would
let us take outside code under it. Describe the change you need in an issue instead.

问题反馈欢迎提 issue（附上 `pip show mars-trace` 显示的版本、执行的命令，以及 job id）。目前暂不接受 pull request：本仓库按 PolyForm Noncommercial License 1.0.0 公开源码，我们还没有接收外部代码所需的贡献者协议。需要改动的地方请写在 issue 里。
